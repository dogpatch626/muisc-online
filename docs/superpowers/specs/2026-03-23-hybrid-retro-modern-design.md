# Hybrid Retro‑Modern UI Design Specification

## 1. Overview
This document describes the design for a hybrid retro‑modern UI that blends the glassmorphic aesthetic of the current project with nostalgic motifs from early 2000s gaming interfaces such as PlayStation 2, Kingdom Hearts, and Jetset Radio. The goal is to preserve core functionality (navigation, media playback, user engagement) while adding pixelated textures, neon glow effects, retro iconography, and menu layouts inspired by those games.

## 2. Architecture
- **App Root**: `main.tsx` with `<ThemeProvider>` and routing.
- **Layout**: `PageShell.tsx` renders the background, navigation bar (`XMBNav.tsx`), and main content.
- **Navigation**: Horizontal top bar with an expandable vertical menu, using `XMBItem` and `XMBCategory`.
- **Content**: Video playback via `VideoPlayer.tsx`, card listings via `VideoCard.tsx` and glass components.
- **UI Library**: Reusable primitives (`button`, `card`, `scroll-area`).
- **Retro Assets**: SVG icons in `src/components/ui/icons/retro/*.svg` and a pixel‑art background image.
- **Styles**: Base glass styles, retro overlay (`glass-layers.css`), neon glow animations, and responsive adjustments.

## 3. Styling Strategy
- **Glass Theme**: `backdrop-filter`, semi‑transparent backgrounds.
- **Retro Overlay**: Repeating pixel texture blended with `multiply` mode, opacity adjustable via CSS variables.
- **Neon Glow**: Box and text shadows with pulse animation on hover; color defined by CSS variable.
- **Iconography**: SVG icons with `fill: currentColor` for theme integration.
- **Menu Layout**: Flexbox horizontal bar, expandable vertical list with pixel borders.

## 4. Accessibility & Performance
- Contrast ratios meet WCAG AA when neon is active.
- Pixel texture kept small (≤ 64×64) and uses `image-rendering: pixelated`.
- Neon glow intensity reduced on mobile to preserve battery and readability.
